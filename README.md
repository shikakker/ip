# Ip

Ip is a product prototype for its core product workflow.

## Features

- Focused end-to-end product flow.
- Responsive interactive interface.

## Tech stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting started

Requirements: Node.js 18+.

```bash
npm install
npm run dev
```

## Available scripts

- `npm run dev` — `next dev`
- `npm run build` — `next build`
- `npm run start` — `next start`
